## Quality gates

- Minimum 900 public words per occupation after source tags and review notes are stripped.
- Minimum 8 tasks per occupation.
- Exactly 4 FAQs per occupation.
- UAE and Saudi sections must be specific, but avoid legal or quota claims that need fragile live verification.
- Use British English.
- Use short sentences.
- No em dashes.
- No employer-sensitive examples.
- No invented statistics.
- No generic filler like "AI is changing everything".
- No "KIM REVIEW" markers in the final public text.
- If an ISCO code is uncertain, mark it with `(verify)` so the renderer hides it.
- Use source tags only where the source genuinely supports the sentence.
- Keep pairwise content similarity below 0.35.
- At least 5 task rows per occupation must be tasks that appear on no other Pack 1 or Pack 2 page.
- No FAQ question may repeat verbatim across occupations.
- Avoid generic "Will AI replace X?" as the first FAQ on every page.
- Each "What this means for you" cell must reference the specific task. If the cell still works when moved to another occupation, rewrite it.
- Each occupation needs one concrete Gulf workflow detail, such as WPS, RERA, three-way matching, GDS systems, e-invoicing, FATOORA, bilingual Arabic-English drafting, or school inspection workflows.
- Run pairwise similarity checks within sibling clusters, not only across the whole pack.
